# Onevra 桌面界面规范与代码架构（第一阶段）

## 目标

Locklark 继续保持本地金库与安全授权边界，桌面主界面以 1Password 8 的高频工作流为参照，用 Onevra 原生组件形成可识别、可维护的产品界面。第一阶段只实现并验证主工作区，不把视觉接近写成完整 1Password 兼容。

验收目标是让用户在同一个窗口内连续完成：

1. 从左侧导航选择工作区、保险库、类别或标签。
2. 在中间列搜索、排序并选择条目。
3. 在右侧查看遮蔽字段，明确显示、复制、编辑或执行条目生命周期操作。

## 技术与边界

- MyGo 继续负责窗口、原生渲染、输入、辅助功能、托盘与平台生命周期。
- Onevra 负责标题栏、主题、Lucide 图标、按钮、输入框、侧栏、列表、滚动区与可拖动分隔线。
- `v2_state.go`、`item_detail.go`、`item_editor.go` 和 `personal.Session` 继续负责数据、授权、审计与事务。
- Onevra 视图只通过既有方法触发业务动作。视图不读取密钥、不绕过遮蔽、不直接修改加密库。
- `onevraUI` 只保存列宽、列表光标和行选择等界面状态。锁库时清除行选择，不持久化秘密或编辑草稿。

依赖固定为 `github.com/oneo-me/onevra/source v0.2026.18`。Onevra 使用 MIT 许可；其 MyGo 衍生组件和 Lucide 资源保留上游许可。

## 主界面结构

窗口初始尺寸为 1240 × 820 DIP，最小尺寸为 980 × 680 DIP。主工作区由两个 Onevra `Split` 组成，形成三栏：

| 区域 | 默认宽度 | 内容 | 关键交互 |
| --- | ---: | --- | --- |
| 导航栏 | 220 DIP | 工作区、保险库、类别、标签及数量 | 选择筛选；宽度可拖动；键盘可调整 |
| 条目列 | 340 DIP | 搜索、排序、列表及主要新建操作 | 键盘选择、双击/Enter 打开；宽度可拖动 |
| 详情区 | 剩余宽度 | 条目详情、字段动作、编辑器和安全报告 | 遮蔽字段显示/复制；明确编辑和状态操作 |

导航最小宽度 190 DIP；条目与详情合计最小 620 DIP。空间不足时 Onevra `Split` 按配置比例收缩，不通过隐藏安全动作解决溢出。

### 标题栏

- 左侧显示 Locklark 标记、产品名、当前保险库与解锁上下文。
- 右侧固定提供快捷搜索、安全设置和立即锁定。
- Windows 使用 Onevra 自绘标题栏和原生控制按钮，保留拖动、最大化与关闭行为。
- 锁定、审批、浏览器确认等安全流程仍由现有窗口逻辑接管，不把主界面装饰放进授权范围。

### 导航栏

- 使用 `SidebarSection` 和 `SidebarItemWithSlots` 显示层级、图标和计数。
- 主要入口依次为：全部、收藏、Watchtower、归档、回收站。
- 保险库、类别和标签分组保持数据驱动，不写死用户条目。
- 当前筛选继续由 `v2State.nav`、`v2State.category`、`v2State.tag` 与 `vaultID` 决定；侧栏只展示该状态。

### 条目列

- 搜索框使用 Onevra `TextBox` 和前导 Lucide 图标，继续调用 `SetSearchQuery`。
- 排序提供标题、更新和创建三个选项；当前选项使用次级按钮面。
- 生成器与新建登录位于同一工具行，保留明确的辅助功能名称。
- 列表使用 Onevra `List` 的键盘选择、类型查找、稳定键和虚拟化能力。
- 行结构固定为类别图标、标题、次标题/网址/相对更新时间、收藏状态与当前行标记。列表只展示 `ItemSummary`，不读取遮蔽字段。

### 详情区

- 未选择条目时显示中性空状态，不猜测用户下一步的敏感操作。
- 头部固定显示类别图标、标题、类别、保险库、编辑、更多和关闭。
- 登录信息与自定义字段使用分组卡片。密码、TOTP 与保护型自定义字段默认遮蔽。
- 显示、隐藏、复制和大号显示继续走现有审计与短期曝光方法，不直接读取详情对象。
- 回收站条目只显示恢复说明和恢复动作；归档条目的状态动作与普通条目分开。
- 历史、收藏、归档和移入回收站保留明确文本动作。

## 视觉规范

- 外观使用 `theme.Onevra`：暖白或暖炭色表面、1 DIP 边框和 8 DIP 基础圆角。
- 主强调色、语义色、文本和表面全部来自主题，不在视图中散落硬编码颜色。
- 间距基于主题 `Space`，正文约为 14–15 DIP，正文辅助信息约为 11–13 DIP，详情标题约为 22 DIP。
- 选中行使用低对比文本色背景并带强调色末端标记；危险与未确认状态使用主题危险色。
- 图标来自固定版本 Lucide，大小随主题和文本缩放调整。图标按钮必须有可读标签与提示。
- 界面不使用装饰性渐变、大面积玻璃卡片或降低安全动作可见性的布局。

## 状态与代码布局

```text
cmd/locklark-desktop
  └─ internal/desktop.Run
      ├─ Onevra plain Shell（窗口、标题栏、主题）
      ├─ App.View（锁定、审批、浏览器、主工作区分流）
      ├─ onevra_view.go（三栏呈现与界面事件）
      │   ├─ onevraHeaderLeading / onevraHeaderActions
      │   ├─ onevraSidebarView
      │   ├─ onevraListView
      │   └─ onevraDetailPane / onevraDetailView
      ├─ onevra_state.go（列宽、列表光标；无秘密）
      ├─ v2_state.go（筛选、快照、选择与业务操作）
      ├─ item_detail.go / item_editor.go
      └─ personal.Session（授权、审计、事务）
```

Onevra 视图是全同步 UI 线程执行器：可启动既有异步方法，但不在构建函数内做文件、网络或密钥操作。每个 frame 的 `ListState` 回调只捕获当前 UI 状态；迟到的列表快照继续由 `v2Query` 代次守卫拒绝。

## 第一阶段的 1Password 对照范围

| 日常任务 | 第一阶段 | 后续 |
| --- | --- | --- |
| 三栏浏览、搜索、排序、选择 | 已接入 Onevra | 固定 1Password 8.x 版本逐屏视觉对照 |
| 显示、复制、编辑、归档、回收站 | 复用既有安全与审计路径 | 撤销、批量操作和更完整快捷菜单 |
| 字段分组、收藏、历史、安全体检 | 有原生入口 | 收藏夹共享、附件预览和跨保险库移动细化 |
| 标题栏、快捷搜索、立即锁定 | Onevra 标题栏与现有原生行为 | Windows Hello 状态与账户头像的真实平台状态 |
| 浏览器保存、填充、OTP、Passkey | 保持现有独立窗口 | 与主窗口内联交互的任务级对照 |

## 验证要求

- `go test ./...`、`go vet ./...` 和 `go build ./cmd/locklark-desktop` 在 Windows 通过。
- Headless UI 测试覆盖三栏可见、导航文本、搜索、空状态和详情动作存在性；普通测试不得弹出窗口。
- Windows 原生 smoke test 使用隐藏窗口和私有合成金库抓取界面；演示截图不包含真实用户数据。
- 键盘必须覆盖 Tab、Enter/Space、分隔线方向键与搜索输入；指针必须覆盖导航、行选择、显示/复制与锁定。
- 反色、文本缩放、最小窗口宽度、锁库清理与 200% DPI 是发布前必检项。
