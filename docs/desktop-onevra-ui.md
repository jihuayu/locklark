# Onevra 桌面界面规范与代码架构

## 目标

Locklark 继续保持本地金库与安全授权边界，桌面界面采用 Onevra 原生组件提供简洁完整的桌面密码管理与开发者工作流：

1. 首次未初始化启动进入 4 步零知识安全引导页（`onboardingView`），不在磁盘预建空 `.ll` 文件。
2. 精简创建本地金库（`createVaultView`）：只需设置/确认主密码并选择保存位置，系统自动生成 Secret Key、在同目录以不可覆盖方式写入 `Locklark-Emergency-Kit.txt`、将 Secret Key 加密写入本机系统凭据库并持久化 `Settings.VaultPath`；日常解锁（`lockView`）收敛为单卡片仅输主密码（保留 `LOCKLARK_DESKTOP_LAYOUT=classic` 以兼容自动化测试）。
3. 退出当前设备（`退出当前设备…`）强制再次验证主密码（缺少本机密钥时需补充应急 Secret Key），清除设备密钥与路径绑定并回到引导页，完整保留磁盘上的 `.ll` 文件。
4. 解锁后在三栏主工作区浏览、搜索、筛选、创建/移动子保险库，在条目前查看/切换 `明文` 与 `加密` 自定义字段，或打开全宽 12 分区设置中心与受控 CLI 集成工作台。

## 技术与边界

- MyGo 继续负责窗口、原生渲染、输入、辅助功能、托盘与平台生命周期；主窗口关闭或最小化时立即锁定金库并隐藏窗口（`a.winHidden`），CLI 后台授权请求弹出置顶独立审批小窗（`a.approvalWin`，`560×430`）。
- Onevra 负责标题栏、主题、Lucide 图标、按钮、输入框、侧栏、列表、滚动区与可拖动分隔线。
- `v2_state.go`、`item_detail.go`、`item_editor.go` 和 `personal.Session` 继续负责数据、授权、审计与事务。
- Onevra 视图只通过既有方法触发业务动作。视图不读取密钥、不绕过遮蔽、不直接修改加密库。
- `onevraUI` 只保存列宽、列表光标和行选择等界面状态。锁库时清除行选择，不持久化秘密或编辑草稿。

依赖固定为 `github.com/oneo-me/onevra/source v0.2026.18`。Onevra 使用 MIT 许可；其 MyGo 衍生组件和 Lucide 资源保留上游许可。

## 启动引导、建库与解锁流

- **首次引导（`onboarding.go`）**：当 `Settings.VaultPath` 为空且默认 `<Documents>/Locklark/personal.ll` 不存在时进入 4 步引导（主密码零落盘 → 本机系统凭据保管 Secret Key → 双因素派生加密 → Emergency Kit 离线恢复）及 5 节点生命周期闭环，提供“创建金库”与“打开已有金库…”入口。
- **精简建库（`createVaultView`）**：移除冗余的 Secret Key 二次确认输入框；默认位置显示文件名与摘要目录并提供“更改…”，点击“创建并进入金库”即原子建库并自动写入不覆盖的 `Locklark-Emergency-Kit.txt`（重名时自动递增 `-2.txt`）。
- **单卡片解锁（`lockView`）**：居中 `MaxWidth(460)` 卡片，仅展示当前绑定金库摘要、密钥状态徽章、主密码输入框、解锁与系统快捷解锁按钮，以及“使用应急资料…”、“打开其他金库…”和“退出当前设备…”。
- **经典布局兼容**：设置 `LOCKLARK_DESKTOP_LAYOUT=classic` 时保留宽屏多卡片解锁界面及 Secret Key 确认流程，确保已有辅助功能与集成测试稳定。

## 主界面结构

窗口初始尺寸为 1240 × 820 DIP，最小尺寸为 980 × 680 DIP。主工作区由两个 Onevra `Split` 组成，形成三栏：

| 区域 | 默认宽度 | 内容 | 关键交互 |
| --- | ---: | --- | --- |
| 导航栏 | 204 DIP | 金库切换器、核心视图、保险库、可折叠类别、标签及非零计数 | 最小宽度 176 DIP；支持新建子保险库；宽度可拖动与键盘调整 |
| 条目列 | 340 DIP | 搜索、排序、类别新建菜单、列表 | 键盘选择、双击/Enter 打开；宽度可拖动 |
| 详情区 | 剩余宽度 | 3 格保护摘要、登录/字段/自定义字段卡片、编辑器和全宽设置中心 | 明文自定义字段直接显示；加密字段默认遮蔽 |

### 导航栏与详情区

- 侧栏顶部切换器支持在全部/指定子保险库间切换，“归档”与“回收站”仅在计数大于 `0` 时显示徽章，“类别”支持展开/折叠，底部直接触发安全设置与锁定。
- 详情头部固定提供类别图标、标题、收藏、编辑、历史版本、更多操作菜单（复制副本、移动/复制到其他保险库、归档、移至回收站）与关闭按钮。
- 自定义字段拆分独立卡片：明文字段显示 `明文` 徽章并直接展示内容与复制动作；加密字段与密码/TOTP 显示 `加密` 徽章并继续走遮蔽与短期审计曝光路径。
- 条目编辑器（`item_editor.go` / `editor_fields.go` / `v2_view.go`）支持行内切换每个自定义字段的 `明文` / `加密` 保护属性，以及通过“+ 添加自定义字段…”弹窗选择是否加密。

### 设置中心（12 分区全宽工作区）

- 在解锁状态下通过独立全宽左导航工作区承载 12 个分区：`general`（通用与默认金库）、`appearance`（浅色/深色/跟随系统与舒适/紧凑实时切换）、`security`（自动锁定、剪贴板清理、遮蔽默认与系统快捷解锁）、`browser`（浏览器 IPC 桥接策略）、`developer`（开发者工具总览）、`ssh`（SSH 密钥与 Agent）、`cli`（24 种 CLI 工具配置工作台）、`cli-activity`（带状态筛选芯片的 CLI 请求活动）、`audit`（签名审计账本）、`transfer`（1PUX/KDBX 导入导出与主密码验证重导应急文件）、`updates`（签名更新）与 `about`（安全承诺与脱敏诊断）。
- **CLI 集成工作台（`cli_integrations.go`）**：涵盖 `cliprofile` 注册表全部 24 种内置工具；支持顶部常用 CLI 快捷栏、可滚动 24 工具清单、多槽位（如 AWS）、文档附件槽位（如 `kubectl`）、动态 `TokenEnvName`（如自定义 `token`）、锁库状态下无凭据 SHA-256 预检，以及 4 步命令行封装向导。
- **CLI 请求活动（`cli_activity.go`）**：支持 `全部` / `已批准` / `已拒绝` / `失败` 四态筛选芯片，并将本机调用元信息与金库签名 `item.run.*` 事件分栏展示。

## 视觉规范

- 外观支持浅色、深色与跟随系统，以及舒适 / 紧凑两种间距密度（紧凑模式将 `Theme.Spacing` 调整为 `3.25 DIP`），修改实时作用于运行中窗口与审批弹窗。
- 主强调色、语义色、文本和表面全部来自 `theme.Onevra`，不在视图中散落硬编码颜色；敏感值绝不进入设置文件、诊断摘要或 CLI 绑定元数据。

## 状态与代码布局

```text
cmd/locklark-desktop
  └─ internal/desktop.Run
      ├─ Onevra plain Shell（窗口、标题栏、主题）
      ├─ App.View（锁定、审批、浏览器、主工作区分流）
      ├─ onevra_view.go（三栏呈现与界面事件）
      │   ├─ onevraHeaderLeading / onevraHeaderActions
      │   ├─ onevraSidebarView
      │   ├─ onevraListView
      │   └─ onevraDetailPane / onevraDetailView
      ├─ onevra_state.go（列宽、列表光标；无秘密）
      ├─ v2_state.go（筛选、快照、选择与业务操作）
      ├─ item_detail.go / item_editor.go
      └─ personal.Session（授权、审计、事务）
```

Onevra 视图是全同步 UI 线程执行器：可启动既有异步方法，但不在构建函数内做文件、网络或密钥操作。每个 frame 的 `ListState` 回调只捕获当前 UI 状态；迟到的列表快照继续由 `v2Query` 代次守卫拒绝。

## 第一阶段的 1Password 对照范围

| 日常任务 | 第一阶段 | 后续 |
| --- | --- | --- |
| 三栏浏览、搜索、排序、选择 | 已接入 Onevra | 固定 1Password 8.x 版本逐屏视觉对照 |
| 显示、复制、编辑、归档、回收站 | 复用既有安全与审计路径 | 撤销、批量操作和更完整快捷菜单 |
| 字段分组、收藏、历史、开发者工具 | 有原生入口 | 收藏夹共享、附件预览和跨保险库移动细化 |
| 标题栏、快捷搜索、立即锁定 | Onevra 标题栏与现有原生行为 | Windows Hello 状态与账户头像的真实平台状态 |
| 浏览器保存、填充、OTP、Passkey | 保持现有独立窗口 | 与主窗口内联交互的任务级对照 |

## 验证要求

- `go test ./...`、`go vet ./...` 和 `go build ./cmd/locklark-desktop` 在 Windows 通过。
- Headless UI 测试覆盖三栏可见、导航文本、搜索、空状态和详情动作存在性；普通测试不得弹出窗口。
- Windows 原生 smoke test 使用隐藏窗口和私有合成金库抓取界面；演示截图不包含真实用户数据。
- 键盘必须覆盖 Tab、Enter/Space、分隔线方向键与搜索输入；指针必须覆盖导航、行选择、显示/复制与锁定。
- 反色、文本缩放、最小窗口宽度、锁库清理与 200% DPI 是发布前必检项。
