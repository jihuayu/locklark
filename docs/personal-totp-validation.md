# 个人 TOTP 配置与受控取码

基线为 PR #3 合并后的 main `c37e833ff4f4bc5c0f1d9810119019b1902f276e`，工作分支 `codex/personal-totp`。从该主线继续，不重写已有生成或披露功能。实现提交、独立复核结论和最终 CI 链接见对应 PR 正文与 Checks。

## 事务和披露边界

`edit-login --field otp` 在不回显的终端输入配置并以 `SAVE` 确认。仅精确空串表示清除；非空由既有严格 TOTP 解析器验证，不猜测/修补输入，也不发网络请求。原生受保护 OTP 字段与 `item.edit.otp` 审计在同一事务保存，成功修订更新；种子/URI不入账或普通输出。此操作只改本地保存配置，不更改网站双因素认证。

`personal otp --file PATH --id ID --revision REV` 的身份、快照、完整审计、login 类型和精确修订都在认证事务内核验。解析已存配置后提交 `item.reveal.otp-code` / `intent`；事务内不计算验证码。数据库关闭后才计算一次并输出到已确认的交互终端。`not-configured` 拒绝绑定当前条目/修订且不推进版本；未知 ID、冲突沿用既有拒绝语义。异常已存配置无成功意图、无输出。普通 raw reveal 白名单没有扩大，种子和生成码保持独立。

计算使用本机时间；起始、提交后和写入前均采样墙钟，去除 Go 单调时钟成分后比较，检测同窗内亚秒回拨和提交期间回拨。计算后检查半开有效区间，精确到 `Until` 拒绝。长提交跨入下一窗时按提交后的时间生成，长输出阻塞可能令实际显示已经过期，不能保证用户看到时仍有效。系统绝对时间可信度与跨进程回拨检测未实现。

stdout 只有 `status: written-to-terminal`、session、intent 与 `[valid_from, valid_until)`；status 仅表明写入器接受完整行，不是人或网站收到的证明。stderr 只显式显示 JSON 字符串验证码。时间/写入失败保留已提交意图，不写已交付事实；短写可能已经暴露一部分，错误不携带 seed/code。临时 Config 在失败/成功返回时调用新增的 owner-only `Clear`；禁止与读取并发清除，不宣称 Go 字符串、旧副本或终端历史被可靠擦除。

## 失败先行和回归

首先运行新增 `TestOTP*`，因 `RevealOTP` 等接口缺失而编译失败，临时日志 `/tmp/locklark-validation/personal-otp-red.log`。实现后的回归包括：

- 真实加密库保存 RFC 示例配置；取码前另一事务能读到已提交意图；59 秒的 8 位码为 `94287082`，时间窗 `[30,60)`，条目修订不变。
- 正常时间、精确截止、同窗亚秒回拨、提交期间回拨、负时间和长提交跨窗；失败零输出、零成功回执，意图仍可验证，临时配置失效。
- 错误因素、未知 ID、旧修订、未配置/清除和非法已存配置拒绝；raw reveal 不接受 `otp` / `otp-code`。
- 事务完成回调后强制回滚，没有意图或计算；输出失败/短写只留意图，秘密错误文案不传播。
- 并发配置修改只允许读到指定旧修订或拒绝，不能以新配置冒充旧目标；备份恢复保留种子及编辑/请求历史，旧修订拒绝，恢复新修订能得到对应码。
- Config 清除的幂等、零字段及后续 `At` 拒绝；原核心 RFC/解析测试保持。
- 真实 PTY/ConPTY 隐藏配置、确认/取消、旧读取器拒绝、受控取码、清除与审计；Python 标准库 HMAC 独立按回执窗口计算码进行对照，不只检查位数。测试不打印转录、种子或码。

## 验证与剩余范围

本轮运行全仓 Go（含 Bun 和 PyKeePass）、OTP/披露定向 race、vet/模块校验、ConPTY 驱动单测、个人恢复/披露/生成/OTP/MCP 进程验收与 macOS arm64 交叉编译。最终结果、Luna/max 独立复核和双平台 CI 针对最终 PR head 核对，记录在 PR 正文。

上述本地检查均通过；全仓个人包 73.806s，定向 race 个人包 279.701s / TOTP 1.066s / CLI 1.113s。PR 为 [#4](https://github.com/jihuayu/locklark/pull/4)，实现 head `f80dab40a0bd04edea7bd0a1ec96d7f0bb792d58`；最终测试/文档修正 head 与双平台链接见 PR 正文。

Luna/max 独立复核未发现阻塞问题，独立 personal/TOTP/CLI 全包测试（58.389s / 0.016s / 8.646s）、构建、OTP PTY、vet 与 diff 检查通过。两项低优先级意见均关闭：文档明确通用回执 `status`；并发测试换成真实不同种子（独立 Python HMAC 计算恢复后的 6 位码为 `326399`），避免只验证格式差异。

这里没有二维码、浏览器填充、手机审批、可信远程时间、通用引用 CLI、op 行为对照或 MCP 原值工具。真实网站登记、原生 macOS/移动端、硬件故障、外部密码评审和完整替换验收仍保留。后续可继续接通个人字段引用的认证事务与明确披露入口，或扩展迁移预检，不能将此功能称为完整 1Password 兼容。
