# 个人密码生成与加密保存

基线为 PR #2 合并后的 main `011814dd9c20a354d6d060cff11fdb32305791a0`，分支 `codex/personal-generation`。实现提交及最终远端检查以本文件对应 PR 的 head 与正文为准；不直接推送 main，也不复用前一轮成功替代当前检查。

## 实现范围

新增 `generate-login` 和 `regenerate-password`，固定现有 62 字符字母数字策略；默认 24 位，可选规范十进制长度 22–256，组合熵至少 128 位。人工在隐藏回显的终端输入因素和必要字段并以 `SAVE` 确认。替换命令明确说明只改本地值、不修改网站密码；稳定 ID 和基准修订必须同时匹配。

随机生成位于 bbolt Update 内，且晚于因素、快照签名、完整审计和目标核验。生成失败返回固定错误，任何封装/审计/事务失败不返回成功回执。新快照与事件原子提交；成功动作分别为 `item.generate` 和 `item.regenerate.password`，带公开 `generation` 策略；拒绝不带该字段。重放据此创建/更新条目修订，读取不产生新的生成事实。

事件新增字段使用 `omitempty`，历史无该字段的签名原文保持不变；新版读取旧库，旧版在新生成事件出现后明确拒绝。生成值不返回公共 API、普通 CLI、审计或错误文案。公开生成函数固定使用 `password.Generate`，私有注入只用于故障测试。Go 字符串内存不保证彻底擦除。此功能不等于自动网站改密、历史版本管理、MCP 取值或 OS 隔离。

## 失败先行与回归

先运行新增测试，因 `GenerateLogin`、`RegeneratePassword` 和 `Event.Generation` 未实现而编译失败；临时日志 `/tmp/locklark-validation/generation-red.log`。后续验证覆盖：

- 生成密码经加密落盘、关库重开后仍可通过独立披露流程查看；公开回执/审计和数据库明文扫描无原值。
- 错误因素、未知 ID、旧修订、损坏审计均不调用生成器；未知 ID/版本冲突只记拒绝。
- 创建和替换时注入随机源失败，完整库文件字节不变；错误不传播随机源私有文案。
- 完成事务回调后注入回滚，旧值和旧修订保留，不返回成功资料，不留生成成功事件。这不是物理磁盘满/断电测试。
- 两个并发替换只有一个成功，另一个冲突；另一个条目及用户名不变。
- 新增、替换的成功策略必须与固定字母数字策略一致；缺失/伪造策略或给拒绝事件附带成功策略均拒绝，即使测试重新签名。
- 含新增/替换生成历史的备份恢复后，原值与历史策略完整，旧库修订被拒，恢复库使用新修订。
- Linux PTY 与 Windows ConPTY 的创建、确认/取消、错误因素、生成保存、显式披露、再生成、旧版本拒绝和审计；测试不打印终端转录或随机值。
- 以 `011814d` 编译的旧 CLI 建库，新 CLI 生成保存后旧 CLI 明确拒绝新历史，未改写旧事件签名。

## 检查与复核记录

使用 Go 1.26.8、Bun 1.4.4、PyKeePass 4.2.0。实跑命令包括 `go test -count=1 ./...`（设置 Bun/PyKeePass 路径）、`go test -race -count=1 ./internal/personal ./cmd/locklark -run 'TestGenerateSaved|TestRegenerate|TestGeneration|TestReveal'`、`go vet ./...`、`go mod verify`、ConPTY 驱动单测和四项终端/进程验收（个人恢复、披露、生成、MCP）。每项最终结果、用户指定 Luna/max 独立复核及发现关闭情况记录在 PR 正文；远端双平台检查针对最终提交核对。

上述本地检查全部通过，定向 race 用时 225.734s / 1.051s，全仓个人包 56.350s。以旧版实际二进制运行生成升级验收通过，macOS arm64 交叉构建通过。PR 为 [#3](https://github.com/jihuayu/locklark/pull/3)，首个实现 head `8458438b50b076c334ddee3982b456f2e1a0de66`；文案修正与交接 head 及最终检查链接以 PR 正文为准。

Luna/max 独立复核未发现阻塞问题，实跑 personal/CLI 全包测试（42.893s / 8.518s）、构建、生成 PTY、定向 vet 和 diff 检查通过。唯一文案意见是生成登录标题为空时不应提示调用者提供密码，已改为只提示标题必填。此复核不替代外部密码评审。

Windows 原生验证由 CI 完成，macOS 本轮仅可交叉编译；真实 1Password 对照、移动真机、系统钥匙串、外部密码评审与完整产品替换条件仍未完成。
