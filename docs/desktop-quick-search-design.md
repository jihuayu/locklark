# MyGo 桌面快捷搜索

基线 main `20e27aa48b6ac855e027cc7abde64fc3c56591f7`，分支 `codex/desktop-quick-search`。前批 [PR #29](https://github.com/jihuayu/locklark/pull/29) 已经精确head `ced61e5391c19d761e3ded615d5afd4074b20906` 的四项 [CI 42133038819](https://github.com/jihuayu/locklark/actions/runs/42133038819) 通过并正常squash合入。本文记录本批实现约定，实际验收与合并状态见 [验收记录](desktop-quick-search-validation.md)。主代理负责设计/独立验收；Sol xhigh实现；Luna max review。

用户流程：通过既有 CmdOrCtrl+Shift+L、托盘“快捷搜索”或原生界面按钮唤起MyGo窗口中的快捷搜索面板。解锁会话内聚焦标题搜索框，Enter或显式搜索按钮提交，显示仅活动登录的标题元数据；用户选定结果后进入既有条目详情，再显式显示/复制。退出面板回到原页面，未提交编辑草稿保留。打开面板清除已有敏感显示及本应用所有权下的剪贴板，不自动读字段、取码、复制、填充或提交网站。

锁定时快捷入口只展示既有解锁界面，不自动调用系统解锁，不加载元数据、不排队执行披露；用户按现有完整因素/系统保护流程解锁后可再次开启快捷搜索。正在处理既有写入/授权/字段交付时只唤起窗口，保持原操作及状态，不用快捷操作取消或替换它。浏览器宿主不注册此桌面入口。

面板独立保存query/results/loading/status和请求代次，不复用主编辑页的字段或rows。调用既有Session.Search(query,"active") / List("active")的worker在UI线程外运行；完成时必须匹配原Session、主generation、面板generation和搜索序号。关闭面板、开始新查询、锁定或更换会话使旧结果失效，不能重新打开、回填列表或覆盖主操作状态。所有错误只显示固定类别。选中行保留稳定ID/修订，后续披露继续走既有精确修订/原生审计检查，不能直接使用查询结果获取字段。

只在本次打开时请求焦点，不能每帧夺焦点；Enter触发搜索，Escape关闭面板，键盘Tab/Enter可选结果。全局快捷键注册失败应在安全设置给出固定的可用性说明并保留本机按钮入口，不能默默声称已注册。保持现有窗口关闭/锁定语义，本批不更改驻留策略或增加后台服务。

验收：先以现有实现实际失败证明快捷键只唤起窗口、未出现搜索面板；UI单测验证默认活动范围、草稿保留、锁定无元数据、忙时不扰动、旧搜索完成丢弃、切换/关闭无秘密显示及焦点/Enter/Escape。真实Linux MyGo/X11由其他窗口前台发实际快捷键，再输入合成标题并Enter、选正确稳定ID、明确显示/复制并核查，取消/锁定不自动披露。原日常生成/TOTP/剪贴板全链路回归、秘密扫描、Luna复审和精确head平台CI；macOS/Windows全局快捷键及真实托盘平台行为仍须原生证据，不能由交叉编译代验。

## 预审后的实现约束

面板替换主内容区，底层编辑/显示按钮不可操作；原输入草稿仍保存在App中。共用主操作入口runContext/runNative在接受任何新操作时使面板代次失效并关闭面板，查询回调另外核对捕获的主操作序号，不能只靠Lock才变化的App.generation。忙态唤起只Show/Focus，无额外状态写入。

最多一个快捷查询worker在途，独立inFlight标志在迟到结果被丢弃后也须释放。查询期间不接受第二个查询，不排队自动搜索；关闭可立即完成，重新打开若旧worker尚未结束则只显示固定处理中状态，结束后必须用户再次显式查询。新查询立即清旧rows并推进序号；不允许旧结果按钮在新查询期间被选择。查询完成仅更新本面板，不写a.status或编辑页rows/query。锁定与session替换清query/rows/loading/focus并撤销本面板代次；旧worker仍须只通过原身份释放自己拥有的inFlight槽，不可释放新worker槽。

主线程回调统一执行唤起入口；MyGo原生回调已在主线程，不为它另起goroutine。窗口Show/Focus保持在实际快捷键回调中以保留Wayland activation token。焦点仅新打开时申请；重复唤起不重置查询、结果或草稿。登记错误显示固定不可用提示；成功仅说明快捷键注册请求已提交，Wayland未有完成通知时不声称已授权，始终保留按钮入口。保持原有托盘/退出策略。

关闭面板保留原编辑页query/rows/selection/草稿；用户显式选择结果则按一次明确条目导航处理：退出面板、切到活动金库视图、带入该次查询和元数据列表、选中稳定ID/修订，清除原条目待提交字段及重新生成确认，不自动披露。测试区分“取消保留草稿”与“显式选中导航”。

新开面板只展示空搜索框与提示，不自动List/Search。Enter或按钮才启动一次明确查询；空串可List(active)，非空完整沿用现有ValidSearchQuery的256字节、Unicode与控制字符限制。List/Search均有认证与审计事务，在worker中执行。关闭只撤销UI结果回填，不能声称已撤回可能提交的搜索审计；不为此额外创建取值授权。

编辑搜索文本立即清掉上次结果并使原结果序号失效，但不自动发起查询；回调还需核对捕获的query。这样在输入新词、尚未Enter时不能把旧rows与新query一起带回主列表。单worker约束不变，迟到worker清自己的槽，不自动接续新文字搜索。

主操作序号必须独立于现有generation/exposureGeneration：既有disclose在a.run之前捕获它们，不能因新快捷面板的通用入口将自己的交付失效。只有新开空闲面板清曝光；普通操作入口在无面板时不得额外清既有曝光或改变其代次。
