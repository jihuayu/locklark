## 功能与信任边界

1. Chromium（Chrome/Edge）和 Firefox 扩展有固定身份；显式注册对应 native host。宿主启动 MyGo 原生窗口，在该进程创建自己的 `personal.Session`，复用完整解锁与系统快捷解锁接口。它不会共享另一桌面进程内的解锁会话。Next.js 管理页面不参与这条秘密通道。
2. 扩展只申请 `activeTab`、`scripting`、`nativeMessaging` 等实际必要权限；没有持续的所有网站访问权，没有网页消息桥或外部扩展接口。候选与填充请求来自扩展自己的弹窗。来源由固定扩展通过浏览器 API 取得；native host 将其视为扩展断言，不能独立证明当前标签页。
3. 原生用户先确认连接，再对每次填充确认精确 HTTPS 来源、条目与修订。只接受当前 HTTPS 顶层文档和现有来源规范，拒绝 iframe、相似域名、隐式子域匹配及不支持的地址形式。扩展在选择、交付和注入时重新核验活动标签页、文档身份与来源。
4. 填充只有用户名和密码，不自动提交。只使用静态注入函数，拒绝歧义、隐藏、禁用或只读目标以及跨来源表单动作；不通过页面事件接收取值指令，不持久化值，不打印值。
5. Native Messaging manifest 白名单和启动参数核验约束正常浏览器调用。当前 OS 用户或管理员可直接启动程序、替换自己的软件；本设计不声称抵御同一用户下的恶意原生程序。系统密钥保护的具体平台边界见桌面验收记录。

## 授权、事务和取消

每条连接只有一个内存能力与一个待确认请求。能力总时长最多 15 分钟，填充意图最多 30 秒；请求使用随机 ID 并绑定来源、标签页、文档、条目和精确修订。锁定、到期、断线、窗口关闭、导航或标签页切换取消待办并清除候选。重新解锁后重新确认连接，旧能力和请求不得复用。

浏览器查询、hello、错误重放或轮询不能刷新金库的空闲时间。只有原生用户操作可以刷新。准备填充时在同一认证事务内重新检查条目 active/login、修订和网站来源匹配；审计意图提交成功后，才能生成短时、一次性用户名/密码交付对象。不能把一次候选匹配与两次普通字段读取拼接成授权。

输出只能写入该连接的串行有界 Native Messaging 管道。协议帧长度、JSON 结构、候选数量、消息数量与字段长度均有界。畸形帧关闭连接；业务拒绝使用固定错误，不回显输入。标准输出只有协议帧。慢管道、取消和锁定不得无限阻塞新操作的拒绝；短时交付后清除临时缓冲。

取消不能收回已经开始写入管道或注入目标文档的字段。交付前以明确的单次消费点决定请求是否仍有效，扩展以文档身份约束目标，绝不把旧回复改投新文档。写出失败、崩溃或回执丢失表示交付未知；不自动重试、不记为网站已接收。审计记录绑定摘要及意图，不记录字段原值。

## 必须实跑的验收

| 层级 | 成功路径 | 拒绝与故障路径 |
| --- | --- | --- |
| 个人金库 | 真加密库匹配、单事务准备、一次消费、审计重开验证 | 错来源、旧修订、归档/回收站、提交失败、锁定、到期、重放与迟到消费；无值或因素写入审计 |
| 宿主协议 | 真二进制长度帧、固定扩展身份、原生配对与确认 | 畸形/超长/重复字段、无配对取值、错误能力、重复 ID、断管、慢写、锁库与确认竞态 |
| 扩展 | 当前顶层文档候选及用户名/密码填充 | 页面消息、错误 sender、HTTP/IDN/IP/相似域名、跨来源 iframe、歧义表单、跨来源 action、切页/切标签、过期回复 |
| 完整链路 | 安装开发扩展和真实 host；合成库经真实 MyGo UI 解锁、配对、确认后填入受控 HTTPS 页面 | 原生拒绝、锁库、导航后旧请求不可填入新页面；确认前不交付，不自动提交，不在日志/存储留值 |
| 平台 | 适用构建、单测、CI；实际跑过的浏览器和 OS 单列 | 编译不能充作 Windows Hello/Touch ID/Secret Service、Firefox native messaging 或 Safari/手机的真实验收 |

真实 GUI 验收使用外部 XTest/等效系统输入及合成因素；产品中不得加入环境变量或测试开关绕过配对、解锁与批准。测试专用构建只能证明协议/模型，不能替代原生端到端证据。实现测试、主代理验收和 Luna 独立审阅分别记录。

保存/更新、TOTP、Passkey、Safari、移动系统填充、完整迁移及团队同步仍是持续范围。本批通过只能关闭配对与登录填充对应条目，不能声称已完全替代 1Password。
