# 本地 SSH agent 与命令凭据

本批提供本地 SSH agent，以及 gh 等常用命令的单次凭据注入。桌面和 CLI 作为独立变更交付，移动端集成继续单独验收。主代理负责架构及独立验收，Sol xhigh 实现，Luna max 复核。以下是实现约定，不是通过声明。

## 两条权限路径

SSH agent 只返回公钥和经本机人工逐次批准的签名，不向客户端提供私钥。GitHub CLI 的 HTTP 认证使用 OAuth access token/PAT；独立命令入口只将所选登录条目的 password 提供给本次可信子进程，例如 GH_TOKEN。不能把 SSH 签名描述为 GitHub HTTP 登录，也不能承诺已交给可信子进程的 token 可以收回。

普通 SSH sign 消息不包含可信主机名。本批显示经系统取得的本机 UID/SID、PID/进程信息、钥匙指纹与“目的地未验证”，逐次批准，不提供长期/整批批准。socket 本身不能识别或禁止所有 ssh -A 转发；不把 PID/路径当作不可伪造的程序证明。未实现并验证 session-bind 前不宣称目的地主机约束。

## 密钥存储与核心

- 新增明确 ssh-key 条目类型，首批支持 Ed25519 生成与未加密 OpenSSH Ed25519 私钥导入。加密私钥导入在实现有界 KDF 检查之前明确拒绝，不进行无界解密尝试。
- 内部规范表示保存32字节 seed，并从它派生/核对公钥；通过既有双因素和 KDBX protected 字段保护，不放进普通登录 password/notes，不在公开 JSON、列表、搜索、引用、MCP 或浏览器投影中暴露 seed。
- 元数据仅含稳定 ID、精确 revision、标题、公钥和指纹。导入限长、固定错误；生成/导入提交必须复用真实个人事务、签名审计与 MutationGate，锁定/取消后不可迟到写入。
- KDBX、备份恢复、归档/回收站、历史/健康检查和既有 login/document 兼容性必须实际覆盖。其他消费端不认识 ssh-key 时明确排除/拒绝，不把它当登录凭据。
- 通用条目元数据带 Kind；旧登录界面排除 ssh-key，专用管理页覆盖 active/archived/trashed。状态修改与待签名取消在同一会话锁内完成；签名意图与批准均不续空闲期限。
- Session 提供窄的生成/导入/ListSSHKeys/PrepareSSHSign/最终签名消费 API；私钥、seed、ssh.Signer 都不返回给桌面或 IPC 层。
- Prepare 只固定元数据与不可变请求，不预读私钥、不预记签名意图。批准绑定 ID/revision、公钥/算法/flags、完整签名数据、连接代次、已认证 peer、请求 ID 与最长30秒的原始期限，数据与公钥须复制避免调用方改写。原生批准窗口显示核心从该不可变副本计算的 SHA256 摘要与字节数，不使用客户端提供的显示摘要。
- 批准后重新验证最新条目与会话，持久提交签名意图并成功关闭事务后才签名；最终签名输出与 RequestLock 在短授权点仲裁。一次消费，取消/断连/超时/旧修订拒绝。socket 写入不持会话锁，已获准交付不能被事后撤回。
- 审计表达签名意图/实际本地结果，不表达远端登录成功；不记录待签消息、私钥、完整命令参数或 token。网络/IPC 请求不延长空闲解锁时间。

## 本地协议与 MyGo

- MyGo 托管 agent 生命周期与原生批准；锁库、退出和禁用服务立即取消待批准请求。开启服务须显式操作，提供可复制的非秘密 SSH_AUTH_SOCK/IdentityAgent 配置，不自动修改 shell 启动文件或停用系统 agent。
- Linux/macOS 使用用户私有目录与 Unix socket，核对真实 peer 用户身份；Windows 使用拒绝远程客户端、用户限定 DACL 的 named pipe，核对客户端 SID。PID/进程名称用于真实来源展示，缺失身份拒绝，不把未知进程伪装成本机可信命令。
- socket/pipe 冲突拒绝；清理只移除本次创建且文件身份未变的端点。不得接管既有系统 ssh-agent。
- Unix 临时父目录规范化后验证整条祖先链：不接受其他用户可替换的祖先，仅允许可信所有者及受 sticky 保护的系统临时目录。不能只验证 socket 的直接私有目录。
- 自行实现窄而有界的 SSH identities/sign dispatcher，复用 x/crypto 的编码、Ed25519 和 OpenSSH 解析，不使用缓存明文私钥的 NewKeyring 或默认会输出错误日志的 ServeAgent。
- 仅支持只读 identities 和 Ed25519 sign（flags=0）；其他 Add/Remove/Unlock/扩展返回固定拒绝。每消息最多64KiB、最多8个连接、4个签名/写出槽位、每连接最多1个预读排队帧和64个请求；读空闲35秒、写出2秒、人工批准30秒，整个连接最长120秒。原生窗口最多1项待审批，不排队无限弹窗。
- 锁定时不返回库内密钥列表，不触发后台自动解锁；原生窗口完成既有完整因素/系统快捷解锁后再允许签名。公钥可显式复制，私钥没有普通读取/导出入口。
- 真正执行 Windows OpenSSH 与 macOS/Linux OpenSSH 连接验证；管道寻址必须实际验证，交叉编译不算平台支持完成。

## 单次命令凭据

- 保留旧 RunEnv 的空标准流语义；新增独立 RunCLI profile，核心绑定真实 stdio 与环境策略，不能沿用宣称 stdio=null 的摘要却执行交互命令。
- CLI 使用隐藏完整因素输入和明确的一次执行确认；先恢复终端模式再启动子进程。选定稳定 ID/revision/password，绝对可执行路径、完整 argv、cwd、超时和环境策略进入签名目标摘要。
- 提供 gh 快捷 profile：GH_TOKEN、独立临时 GH_CONFIG_DIR 与 HOME/XDG 配置区；不执行 auth login、不写用户全局 gh 配置、不改变父进程或 shell 的 token 环境。
- 允许明确选择的常见单 token 环境变量；拒绝加载器/命令解析/系统路径等控制变量。主程序不通过 shell 或 PATH 查找。需要的辅助命令目录使用明确的公开配置，不能继承未审阅的代理、debug、token、SSH_AUTH_SOCK、主机/配置覆盖或加载器环境。环境从空集合和明确策略构造，不复制父环境再尝试删减。
- 子进程直接继承 os.Stdin/Stdout/Stderr 并保留退出码，可能是终端或用户管道；批准绑定该 inherit-stdio 策略，隐藏因素和确认仍须真实控制终端，不能把非交互调用当作批准。包装器不捕获、记录子进程正文。它是经用户授权向可信本机程序披露原值，不是沙箱；程序及其后代能读取、打印或转交 token，界面/文档须如实表达。
- RunCLI 的因素与确认通过独立控制终端读取和显示，保留原始 stdin/stdout/stderr 给子进程；没有控制终端则拒绝。验收须包含 stdin 与 stderr 管道，确认提示不能污染它们。
- 临时配置根须处于可信父目录下；Unix 与 agent 共用祖先信任检查，Windows 从系统 Known Folder 获取父目录并核对所有者、ACL 与重解析点，不能信任调用方 TEMP/TMP 指向的任意目录。
- 意图持久提交后才执行；取消在启动前胜出则零启动。进程创建/终止与临时目录清理失败要明确报告，不能把未知执行状态当成功。命令行、普通报告、日志和长期配置不得包含凭据。

## 分工与验收

SSH 核心作者拥有 vault/personal 的类型、事务、journal、签名 API；IPC/MyGo 作者只消费窄接口，不自行解密条目；命令作者拥有独立 RunCLI 文件与 CLI 入口，并与核心作者协调共享事务文件，避免并发覆盖。主代理提供最终行为验收，Luna 复核产品和工具。

验收使用真实加密库、MyGo 窗口、OpenSSH 客户端和受控 SSH 服务，核对正确签名、拒绝、锁库、旧修订、超时/断连、并发、慢消费者、未知协议及无私钥流出；新类型往返 KDBX/备份，并回归原登录/文档/浏览器/MCP边界。命令验收使用真实终端与实际 gh 子进程（受控 TLS 端点/显式测试包装器），验证环境仅在本次子进程、可用标准流、退出码、拒绝零启动、不持久保存、不污染父环境和完整输出 canary。公开测试证据不包含秘密；工具通过不代替真实平台运行。
