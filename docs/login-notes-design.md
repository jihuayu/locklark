# 登录备注：架构与验收约定

从 PR #30 已合入的 main `87fcd7c4f26ba19277ca0fdc3c6341098e82a3da` 接续。主代理负责本设计及独立验收，Sol xhigh 实现，Luna max 独立审阅。本切片补齐登录条目的纯文本备注及迁移，不把它标记为独立安全笔记类别或完整 1Password 兼容。

## 数据与迁移

- `vault.Item.Notes` 为可选字符串，JSON 空值省略以保持旧条目摘要兼容。仅 login 可使用；UTF-8/XML 合法文本，最大 64 KiB（字节），计入原整库预算。保留换行、空格、Unicode 和顺序，不 trim、归一化或执行富文本。
- KDBX 使用标准、必须受保护的 `Notes` 字段；空值不写。读取拒绝不受保护、超限、错误类别或未知字段，旧无备注条目可读。加密迁出由 PyKeePass 独立核对正文及保护位；原始 ImportSource 保持不可变，编辑备注不会抹去源中旧值。
- 1PUX 登录映射扩展 `details.notesPlain` 为可选字符串；缺失/空值均为空，错误类型、超限或不支持类别/区段/历史等仍整批拒绝。新报告 profile/status 为 `login-notes-v2`，计划 HMAC 域同步更新，旧计划必须重新确认。源身份派生域保留原 login/v1，防止升级后重复导入同源条目。

## 权限与事务

- 列表、标题搜索、快捷搜索、体检、原生非秘密 metadata view、Next.js、浏览器候选/填充/保存/OTP DTO 均不带备注，不自动读取正文。
- 原生明确显示、复制、编辑前填入分别记录 `item.desktop.show.notes`、`item.desktop.copy.notes`、`item.desktop.edit.notes` 意图，然后经现有一次性 NativeField 交付。三个动作只允许固定 notes 字段；其他字段不能使用 edit 目的。
- 保持公开 `ValidRevealTarget`、CLI reveal、引用、inject/run、MCP 和浏览器原值能力范围不变；原生验证单独允许 notes，禁止通过扩宽共享校验器间接开放其他通道。
- 保存动作 `item.edit.notes` 绑定原 ID/修订、同事务审计与数据变更，复用 Native MutationGate，明确区分取消、冲突和提交后未知。空正文是显式清空；拒绝错误类型/非法文本/超限，错误与回执不得带正文。CLI 既有 edit-login 可以明确支持 notes 的隐藏单行替换，但多行编辑通过原生编辑器，不增加命令参数原值。

## 原生使用流程

- 登录详情增加“显示备注”“复制备注”“编辑备注”。选中条目不会自动披露；显示复用 15 秒隐藏，复制复用 30 秒系统 ownership lease。显示是纯文本并防显示控制字符误导，不解释 Markdown/链接。剪贴板原始 UTF-8 字节通过 X11 `UTF8_STRING` 独立核验；接收程序选择的系统文本格式可能规范化换行（如 GTK 的 text/plain 接口），不能将接收端格式转换等同于金库存储改写。原文经编辑器不修改再保存及 KDBX 导出仍须逐字节一致。
- “编辑备注”是明确披露动作，成功审计及一次性交付后才进入独立多行编辑器，固定显示目标 ID/修订。保存与取消为独立按钮；不以 Enter 自动保存。编辑器本身是有意识的可见秘密输入，提示保存前可取消。
- 编辑器固定原目标；锁定/换页/换条目/明确快捷结果选择清空草稿。取消不写内容、不改原修订。快捷面板临时打开与 Escape 返回可以保留该编辑草稿，与原快捷搜索草稿约定一致；快捷查询/结果不接触正文。锁定优先于任何迟到读取或保存回调；禁止自动重试。
- 保存捕获后清空 UI 草稿，工作线程的字节缓冲在结束后清理；无法承诺 Go 字符串物理擦除。成功刷新并需要重新明确读取；冲突不覆盖新内容，不把原值写入错误或状态。

## 验收门槛

先有运行失败的行为测试，再实现：旧库兼容、受保护 Notes 往返、64 KiB 边界及无效类型、1PUX 新 profile/旧计划拒绝/重复身份、编辑后源记录不变、空值清除、归档/回收站规则、审计先行、过期/锁定/双编辑冲突/取消/提交未知、NativeField 单用及全部非秘密 DTO 不含正文。

外部真实流程须从正常 CLI 迁入合成多行备注，在 MyGo 中明确显示/复制/编辑/取消/保存/重开，检查剪贴板清理和锁定；同份修改后的 KDBX 通过 PyKeePass 检查字节与保护位。保持旧桌面日常、快捷搜索及两浏览器回归。控制器只记录固定阶段/计数/布尔值，正文及因素只在私有管道/临时材料，扫描完整 stdout/stderr 和产物。Sol 外部工具验收不替代主代理固定构建的独立重跑；Luna review 不冒充 GUI 或硬件验收。
